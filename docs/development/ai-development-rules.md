# AI Development Rules

## Workflow

1. Leer primero la especificación correspondiente.
2. Modificar un solo archivo por iteración.
3. No cambiar la arquitectura sin actualizar la documentación.
4. No agregar librerías sin aprobación.
5. Mantener componentes pequeños.
6. Mantener compatibilidad con Next.js App Router.
7. Todo cambio debe cumplir la especificación del producto.
